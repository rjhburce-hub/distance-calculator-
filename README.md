# Distance-Calculator.py

## Description
This program converts kilometers to miles

## How to Run
1. Open program file in Programiz or VS Code
2. Run the program
3. Enter the distance in kilometers to be converted to miles

## Input needed
- kilometers (1)
- yes/no
- kilometers (2)

## Sample Output
Enter kilometers (1)= 34
The distance in miles is 21.123314
Enter yes/no (if you want to convert again)=yes
Enter kilometers (2)= 90
The distance in miles is 55.92339
